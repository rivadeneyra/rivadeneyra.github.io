# rivadeneyra.github.io

Personal academic website of Francisco Rivadeneyra, live at https://rivadeneyra.github.io/.

## Files

- `index.html`: the whole site, one page with selected work, research, talks and media, about, and contact.
- `cv.pdf`: the CV linked from the site.

## Updating

- **Text:** open `index.html`, click the pencil icon, edit the words between the tags, and commit. The site refreshes within a minute or two.
- **CV:** Add file › Upload files, upload the new PDF named `cv.pdf`, and commit. It replaces the old one.
- Every change is kept in the commit history, so any earlier version can be restored.
